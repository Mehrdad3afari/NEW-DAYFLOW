# برنامه هفتگی ریتم

نسخه‌ی وب فارسی و راست‌چین برای برنامه‌ی هفتگی دانشگاه، کار و فعالیت‌های شخصی.

- نمایش برنامه‌ی هفته به تفکیک ساعت و روز
- انتخاب روز و فهرست خوانای فعالیت‌ها در موبایل
- تیک‌زدن فعالیت‌ها و نوار پیشرفت روزانه
- افزودن ریزفعالیت با ساعت اختیاری؛ تغییرها در مرورگر ذخیره می‌شوند

این اپ در پوشه‌ی `weekly-planner/` قرار دارد. گردش‌کار انتشار آن در `.github/workflows/ritm-pages.yml` است و فقط همین پوشه را روی GitHub Pages می‌فرستد.
